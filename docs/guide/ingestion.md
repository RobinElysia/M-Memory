# 记忆摄入指南

## ingest() 参数

```python
engine.ingest(
    summary="一句话摘要",        # A: 用于桶级粗筛
    content="完整的对话内容...",  # C: 用于精确检索 + 冲突消解
    confidence=0.9,             # 来源置信度 0.0-1.0
)
```

## summary vs content 的区别

| | summary (A) | content (C) |
|---|-------------|-------------|
| 长度 | 短（一句话/几个关键词） | 长（完整对话） |
| 用途 | 粗筛：与桶 Medoid 比相似度 | 精筛：与查询做语义匹配 |
| 向量存储 | Medoid 索引 | Content 索引 |
| LLM 使用 | 分桶决策上下文 | 矛盾检测 |

**最佳实践**：summary 应该是 content 的精简概括，类似文章的标题。
这样 A 向量与查询的相关性更高，粗筛效率更好。

## 分桶行为

第一次摄入时，系统自动创建第一个桶。后续摄入：

1. 计算新节点 A 向量与所有桶 Medoid 的相似度
2. 取 top_k 个候选桶
3. 调用 LLM 决策：归入某桶 / 创建新桶 / 跨桶关联

## 跨桶关联示例

当用户说"我的猫和狗都喜欢吃鸡肉"时，这个内容既涉及猫主题又涉及狗主题。
LLM 可能决定：归入猫桶（主桶），同时对狗桶建立跨桶边（权重 0.7）。

这样后续查询"狗吃什么"时，通过图扩展也能找到这条跨主题的记忆。

## 置信度建议

| 场景 | confidence |
|------|-----------|
| 用户明确陈述 | 1.0 |
| 推测/推断内容 | 0.6-0.8 |
| 模糊/不确定 | 0.3-0.5 |
| 已知矛盾 | 0.1-0.2 |
