# 分桶与聚类

## 与传统聚类的区别

| | K-Means | DBSCAN | m-memory Bucket |
|---|---------|--------|-----------------|
| 簇数 | 预设 K | 自动 | LLM 动态决定 |
| 分配 | 硬分配（最近中心） | 密度可达 | LLM 语义判断（可跨桶关联） |
| 代表点 | 算术质心（可能不是实际点） | 核心点 | Medoid（实际节点） |
| 新类别 | 不可能（K 固定） | 噪声点 | 随时创建新桶 |

## 增量分桶流程

```
新节点到来
  │
  ├──→ embed(A) → 计算与所有桶 Medoid 的余弦相似度
  ├──→ 取 top_k 候选桶
  ├──→ 构造 LLM prompt（当前摘要 + 候选桶上下文）
  │
  └──→ LLM 决策
        ├── 归入候选桶 A → 物理存入 + 可能建跨桶边
        ├── 归入候选桶 B → 同上
        ├── 创建新桶   → 以该节点为初始 Medoid
        └── 软关联     → 归入主桶，同时对其他相关桶建跨桶边
```

## LLM 决策的上下文

为了让 LLM 做出合理的分桶决策，我们不仅提供候选桶的 Medoid 摘要，
还提供桶内离 Medoid 最近的少数几个节点的摘要，作为"桶的语境"。

这样 LLM 可以看到桶的主题范围，避免因为 Medoid 恰好是边缘节点而导致误判。

## Medoid 漂移

每当有新节点加入桶，只重新计算该桶的 Medoid（以及极少数与之有跨桶边的桶的 Medoid）。
不需要重建所有桶内边——Medoid 以元数据指针形式存在，漂移时同步更新摘要和版本号。
关联桶的 Medoid 若受影响，则异步标记待刷新，不阻塞写入路径。
